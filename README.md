# 🏥 Patient Management System

## 📌 Overview  
The **Patient Management System** is a **scalable, enterprise-grade web application** meticulously architected using **Spring Boot** and **Thymeleaf** to streamline patient data management. This system is designed to handle **dynamic CRUD operations**, ensuring efficient data integrity while offering **seamless real-time querying capabilities** through a robust search mechanism.  

Built on a **service-oriented architecture (SOA)**, this system enforces **domain-driven design (DDD) principles**, ensuring modularity and maintainability. The database layer leverages **Hibernate ORM** with **JPA annotations**, facilitating optimized query execution, while the controller layer adheres to **RESTful principles**, enabling efficient client-server communication.  

🔹 **Create** and persist patient records with strict data validation.  
🔹 **Retrieve** structured patient data through indexed queries.  
🔹 **Update** entity attributes while ensuring ACID compliance.  
🔹 **Delete** records with referential integrity enforcement.  
🔹 **Search** patients with **optimized pattern-matching algorithms** (returns “Search failed” if no results).  

## 🛠️ Tech Stack  
- **Backend**: Spring Boot (Java) with layered architecture  
- **Frontend**: Thymeleaf, HTML5, CSS3  
- **Database**: MySQL (production) 
- **ORM**: Hibernate ORM with JPA (Java Persistence API)  
- **Security**: Spring Security (for future authentication integration)
